Backups are created here automatically before any system change:
  Registry\<timestamp>\   registry exports (.reg) + created-key manifest
  settings_<timestamp>.ini configuration copies
  services_snapshot.txt   services paused by Gaming Mode
  powerplan_snapshot.txt  previous power plan GUID
Restore everything via main menu [11] "Restore Previous Settings".
The 10 newest registry sets are kept; older ones are pruned automatically.
