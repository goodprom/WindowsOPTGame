Place optional external tools in this folder.

Supported:

  RAMMap64.exe / RAMMap.exe  (Microsoft Sysinternals)
    Used by Gaming Mode and RAM Cleanup to safely empty the standby
    memory list. Download from:
    https://learn.microsoft.com/sysinternals/downloads/rammap
    Extract RAMMap64.exe directly into this folder.

If no tool is present, the optimizer skips the related step and explains
what to download - it never uses undocumented memory-cleaning tricks.
